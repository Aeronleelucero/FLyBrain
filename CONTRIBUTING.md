# Contributing to FlyBrain

FlyBrain accepts issues and pull requests to the Official Repository at the
Copyright Holder's discretion. Submitting a pull request does not grant
repository administration rights, release rights, ownership of the Official
Repository, or rights to use the FlyBrain name or branding.

## Before submitting

- Discuss substantial changes in an issue before investing in an implementation.
- Keep changes focused and include relevant tests and documentation updates.
- Do not submit secrets, credentials, private data, proprietary datasets, or
  material that you are not entitled to contribute.
- Preserve all copyright, license, attribution, and provenance notices.
- Ensure your contribution complies with the FlyBrain Source-Available
  Non-Commercial License and the Code of Conduct.

## Contribution terms

By submitting a contribution to the Official Repository, you agree to the
contribution license in Section 5 of LICENSE. In short, you keep rights in your
original contribution, while granting the Copyright Holder the right to use,
modify, distribute, sublicense, and relicense it as part of FlyBrain. The
Copyright Holder decides whether and when to merge or release contributions.

## Development

Install development dependencies with `pip install -e '.[dev]'` and run
`python -m pytest -q` before opening a pull request.
